# Security

The skills and runbooks here run Python and launch agents on your machine, so a vulnerability report is welcome even when you are not sure it is one.

Report it privately: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for it.

Say what you ran, on which version or commit, and what happened. You will get a reply within a week. Fixes go to `main`; there are no maintained older versions.
