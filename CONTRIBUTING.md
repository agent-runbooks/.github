# Contributing

Bug reports and small fixes are welcome as they are. For anything larger, a new skill, a new runbook, a change in how the engine behaves, open an issue first, so we agree on the shape before you write it.

- One change per pull request.
- Run the checks the repository's CI runs, they are in `.github/workflows`. A pull request needs them green.
- A runbook idea for the gallery goes through the "Runbook idea" issue template there.
- Questions and show-and-tell go to [Discussions](https://github.com/agent-runbooks/skills/discussions).

Security problems: see [SECURITY.md](SECURITY.md), not a public issue.
